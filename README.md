# Galactic Gumball Machine — interactive prototype

A cosmic, interactive redesign concept for [GalacticGumballMachine.com](https://galacticgumballmachine.com).

Twist the machine and a gumball dispenses with a color + symbol and a 3-minute creativity activation. Living starfield, the Cosmic Codex legend, and generated sound.

`index.html` is fully self-contained (artwork embedded) — just open it in a browser.
